**🧾 FaceValue**

A tool that speeds up physician contract cost-allocation — FMV lookups plus ASA/PSA calculators — so contract teams can benchmark pay against AAMC/MGMA/Sullivan Cotter data in minutes instead of hours.

**Live demo:** [facevaluetool.netlify.app](https://facevaluetool.netlify.app/)

## What it does

- Upload benchmark surveys (Excel/Word) and auto-detects specialty, percentile, and compensation columns
- Runs FMV (Fair Market Value) lookups against those benchmarks
- Calculates ASA/PSA cost allocations for physician contracts
- Flags submissions that fall outside benchmark ranges

## About this repo

This currently holds `facevalue.jsx`, the core React component behind the tool. It's shared here for review as a code sample rather than as a full runnable project — the live demo link above is the best way to see it in action.

Built with React and the `xlsx` and `mammoth` libraries for parsing uploaded files.
